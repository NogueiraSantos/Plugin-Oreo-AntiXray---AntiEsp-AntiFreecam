Plugin Vibecodado com utilização do Opus 5 bem simples sobre AntiXray, AntiEsp e AntiFreecam

Configurável na config.yml o Y-Level

Sistema de Fake minérios (alerta o operador no chat ou console sobre possível jogador usando Xray)

Comandos:
/oreoantixray alerts - 
/oreoantixray inspect {player} - 
/oreoantixray status

Mensagens configuráeis em messages.yml

Versões em que o plugin suporta é dá 1.21+

Dependências: **PacketEvents**
